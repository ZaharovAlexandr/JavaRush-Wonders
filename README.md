# 🏛️ JavaRush-Wonders 

> Мой первый проект на курсе FullStack Web-Developer от JavaRush.

Визитная карточка проекта, демонстрирующая навыки верстки и базовой интерактивности. Это страница для бронирования путешествий от одной станции к другой.

[**🌐 Посмотреть проект вживую**](https://zaharovalexandr.github.io/JavaRush-Wonders/)

---

## 🚀 О проекте

В этом проекте я реализовал полноценный интерфейс с использованием чистого CSS, HTML, JS. Основной акцент сделан на семантическую верстку, адаптивность и логику взаимодействия с пользователем (бронирование, выбор дат, счетчики).

### Что реализовано:
*   **Интерактивное бронирование:** выбор типа поездки (в одну сторону / туда-обратно).
*   **Счетчик пассажиров:** динамическое управление количеством людей с валидацией кнопок.
*   **Кастомные элементы ввода:** работа с датами и стилизованные плейсхолдеры.
*   **Адаптивная верстка:** страница корректно отображается на различных устройствах.
*   **Фильтрация:** фильтрация массива станций при вводе текста.

---

## 🛠️ Стек технологий

*   **HTML5** — семантическая структура документа.
*   **CSS3** — стилизация, Flexbox и Grid Layout.
*   **JavaScript (ES6+)** — логика управления интерфейсом и модульная структура кода.
